YAIIU Photo Server has been deployed.

1. Set these server credentials using extraEnv values from a Kubernetes Secret:
   - STANDALONE_API_KEY (at least 32 characters)
   - STANDALONE_EMAIL
   - STANDALONE_PASSWORD (at least 12 characters)

   In Immich mode, set config.immichServerURL and use an Immich account in YAIIU.
   IMMICH_API_KEY is optional; it enables background retries and backlog delivery.

2. The archive is mounted at {{ .Values.config.dataDir }} on persistent storage.

3. Health check: GET /health
   YAIIU background upload endpoint: POST /api/assets/background
   YAIIU foreground upload endpoint: POST /api/assets
   Read-only archive listing: GET /api/archive/assets
